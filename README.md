# CoalSys3, 3.0.0
Coal System 3 presented by Coal-84x is a custom-made Command-Line Interface specifically made to simplify windows commands and heavy abstractions
CoalSys3 were introduced as a replacement for Coalvm and CVM++. In order to start CoalSys3, you must allow CoalSys3 to access towards administrations or not.

PLEASE READ MIT LICENSE BEFORE INITIALIZING OR INSTALLING COALSYS3 AND DOWNLOAD THE EXECUTABLES IN RELEASE, if windows give a warning label, click: "continue anyway",
and you may proceed to the command line.

### exit;
exiting program
